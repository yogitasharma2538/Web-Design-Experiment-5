
# Experiment 5: Weather App

## Aim
To create a weather application using JavaScript and Fetch API that retrieves real-time weather information based on user input.

## Description
This project is a simple weather application that allows users to search for a city and view its current weather information.

The application uses the Open-Meteo API to retrieve weather data without requiring an API key.

## Features
- Search weather by city name.
- Display current temperature in Celsius.
- Display humidity percentage.
- Display wind speed.
- Handle invalid city names and API errors.
- Responsive and user-friendly interface.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Fetch API
- Open-Meteo API

## APIs Used
1. Open-Meteo Geocoding API – Finds the latitude and longitude of the entered city.
2. Open-Meteo Weather API – Fetches current weather information using geographical coordinates.

## Files Included
- index.html – Structure of the application.
- style.css – Styling and layout.
- script.js – Fetch API and weather functionality.

## How to Run
1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open index.html using Live Server.
4. Enter a city name in the search box.
5. Click the Search button to view weather details.

## Outcome
Successfully developed a weather application using JavaScript Fetch API and Open-Meteo API to display current weather information based on user input.
